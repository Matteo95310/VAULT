On the second week, we worked with **SQL**, **SQL** is used to create **tables** and **databases** for our website.

Then you can **open** it and start to write in it

Launch **PhpMyAdmin**

Start a new page in **SQL**

use the command :

“**CREATE DATABASE IF NOT EXISTS**  ‘name of the database’

&#x09;**COLLATE** utf8mb4\_unicode\_ci“
